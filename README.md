# COMP-4450-Assignment-3

## Endpoints

**/health**: Endpoint confirming whether the API is running or not.
**/predict**: Endpoint that takes an input movie review and returns the sentiment of the review (positive or negative).
**/predict_proba**: Endpoint that takes an input movie review and returns the sentiment and the confidence score of the sentiment. i.e "positive", 0.95.
**/example**: Endpoint that returns a random review from the original training dataset.
